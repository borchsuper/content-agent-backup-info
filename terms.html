Условия использования

Content Agent Backup предназначен для личного использования владельцем Google-аккаунта и его сервера. Приложение не предоставляет услуги резервного копирования другим пользователям.

Владелец предоставляет доступ только к тем данным, которыми вправе распоряжаться, и управляет доступом Google, своим сервером, резервами и ключом расшифровки.

Работа зависит от доступности Google Drive, сервера, сети и используемых программ. Наличие резервного файла не гарантирует его пригодность для восстановления: результат проверяется отдельным чтением и пробным восстановлением.

Для прекращения использования владелец отключает задания резервирования, отзывает доступ в Google и при необходимости удаляет сохранённые копии. Потеря ключа расшифровки может сделать зашифрованные данные недоступными.

Обработка данных описана в политике конфиденциальности.
