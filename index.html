Content Agent Backup

Личное приложение для резервного копирования файлов Content Agent в Google Drive владельца.

Приложение предназначено для создания и проверки зашифрованных резервных копий с помощью rclone и restic. В резерв могут входить пользовательские файлы и необходимые сведения для восстановления работы.

Запрашивается разрешение Google Drive drive.file: создание файлов и работа с файлами, к которым пользователь предоставил доступ этому приложению. Приложение предназначено для владельца, публичная регистрация не предусмотрена.

Правила обработки данных описаны в политике конфиденциальности. Порядок использования описан в условиях.
