Milora Backup

Личное приложение для резервного копирования выбранных владельцем файлов в его Google Drive.

Приложение создаёт резервные копии, хранит предыдущие версии и проверяет возможность восстановления. Оно читает выбранные владельцем исходные файлы и сохраняет архивы в указанную им папку Google Drive.

Приложение предназначено для личного использования владельцем аккаунта. Этот сайт содержит только описание приложения и правила работы с данными.

Текущее разрешение https://www.googleapis.com/auth/drive позволяет работать с файлами Google Drive. Его назначение — чтение выбранных исходных файлов, запись резервов и проверка восстановления. Подробности — в политике конфиденциальности.
